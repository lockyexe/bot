# Practice Pathfinder

A humanized **Practice Mode auto-solver** for making showcases.

It plays the level for you with trial and error: it clicks through the same input path the game uses, so your own macro recorder (xdBot, Mega Hack, Eclipse...) captures every input like you clicked.

- **F6** turns it on/off mid-run (only plays in Practice Mode)
- Places checkpoints by itself, learns from every death, and backtracks out of dead-end checkpoints
- Humanized: tries no input first, then single clicks, then multi-clicks; keeps holds/releases at 12-16 ticks; flies ship/wave/UFO/swing on a drifting line instead of 1-tick straight-fly; picks orb and jump timings from the middle of their windows

It does **not** record macros or change game speed - use your own tools for that.
